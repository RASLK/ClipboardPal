# ClipboardPal

Кроссплатформенный расширенный буфер обмена (**Windows / macOS / Linux**) на **Avalonia + .NET 10**.
Опыт в духе PastePal: панель карточек, поиск (Regex и без учёта раскладки en↔ru), быстрый выбор цифрами, темы, гибкие настройки.

## Стек

| Слой | Технология |
| --- | --- |
| UI | Avalonia 11, FluentTheme |
| Runtime | .NET 10 (LTS) |
| MVVM | CommunityToolkit.Mvvm |
| Hotkeys | SharpHook (libuiohook) |
| OCR | Системные движки (Apple Vision / Windows OCR) + встроенный PP-OCRv5 на ONNX Runtime |
| DI | Microsoft.Extensions.DependencyInjection |

Данные: `%LocalAppData%/ClipboardPal` (`history.json`, `settings.json`, `images/`, `ocr/`, `sounds/`, `backups/`).

Языки интерфейса: английский (по умолчанию), русский, немецкий, французский, китайский, японский — переключатель первым пунктом в настройках.

## Возможности

- Глобальный хоткей (по умолчанию Win/Cmd+Shift+V)
- Панель снизу/сверху/слева/справа, темы
- Три пространства с вкладками в шапке панели: **История**, **Очередь**, **Корзина**
- Очередь — отдельное временное пространство: откладывайте клипы кнопкой **+** на карточке, переключайтесь на вкладку «Очередь» и вставляйте по одному. Вставленный клип уходит из очереди, но остаётся в истории (настраивается); очередь переживает перезапуск.
- Поиск + Regex + раскладко-независимый поиск
- Быстрый выбор: модификаторы + 1…0
- Закрепление, переименование, лимит до 100 000, исключения приложений
- Трей, автозапуск, горячий край, звук копирования

## OCR

Работает офлайн из коробки — ничего не нужно устанавливать или скачивать. Сначала используется системный движок (Apple Vision на macOS, Windows OCR на Windows), иначе — встроенная модель PP-OCRv5 (латиница + кириллица) на ONNX Runtime; она зашита в исполняемый файл и распаковывается при первом использовании.

У каждой карточки-картинки есть кнопка **OCR**: она открывает изображение в окне выбора области — нарисуйте рамку, потяните за ручки, масштабируйте колесом (вид следует за выделением). Распознанный текст попадает в буфер обмена и отдельной текстовой карточкой в историю. Повторное нажатие — новый выбор области.

## Сборка

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```bash
cd ClipboardPal
dotnet restore
dotnet run --project src/ClipboardPal.App -c Release
```

Релиз: тег `v2.0.2` → как у Flameshot: **MSI+ZIP** (Win), **DMG** (macOS), **AppImage+ZIP** (Linux) и файлы **`.sha256sum`** (проверка целостности скачивания). Workflow только на тегах.

Подробнее — в [английской версии README](../README.md).
